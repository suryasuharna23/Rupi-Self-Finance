# RUPI-503 · WhatsApp channel

| Phase | Priority | Size | References |
| --- | --- | --- | --- |
| 5 · Advanced features | P2 | L | scope: Advanced 2 |

## Scope
- A WhatsApp Channel Adapter (WhatsApp Business Cloud API) with webhook signature verification.
- Confirmation buttons use WhatsApp interactive messages.
- Link a WhatsApp number to the same account as Telegram (optional).

## Acceptance criteria
- [ ] The logging, correction, and summary question flows work the same as in Telegram.
- [ ] Webhooks with an invalid signature are rejected.

## Dependencies
Phase 4 gate.
