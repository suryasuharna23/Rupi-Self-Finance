# RUPI-501 · Web chat and chart dashboard

| Phase | Priority | Size | References |
| --- | --- | --- | --- |
| 5 · Advanced features | P2 | L | FR-04, scope: Advanced 2 |

## Scope
- A web Channel Adapter (HTTP/WebSocket) that calls the same Conversation Service.
- Link a web account to a Telegram account via a one-time code (FR-04).
- Dashboard: spending per category, daily trend, budget status.

## Acceptance criteria
- [ ] Transactions logged in Telegram show up immediately on the web, and vice versa.
- [ ] Link codes expire and can only be used once.

## Dependencies
Phase 4 gate.
