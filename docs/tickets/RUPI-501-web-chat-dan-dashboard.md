# RUPI-501 · Web chat dan dashboard grafik

| Fase | Prioritas | Ukuran | Referensi |
| --- | --- | --- | --- |
| 5 · Fitur lanjutan | P2 | L | FR-04, ruang lingkup Lanjutan 2 |

## Cakupan
- Channel Adapter web (HTTP/WebSocket) yang memanggil Conversation Service yang sama.
- Hubungkan akun web dengan akun Telegram lewat kode sekali pakai (FR-04).
- Dashboard: pengeluaran per kategori, tren harian, status budget.

## Kriteria penerimaan
- [ ] Transaksi yang dicatat di Telegram langsung terlihat di web, dan sebaliknya.
- [ ] Kode tautan kedaluwarsa dan hanya bisa dipakai sekali.

## Dependensi
Gerbang Fase 4.
