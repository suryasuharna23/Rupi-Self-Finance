# RUPI-307 · Comparison with the previous period

| Phase | Priority | Size | References |
| --- | --- | --- | --- |
| 3 · Events, budgets, reports | P1 | S | FR-23 |

## Scope
- Add a per-category comparison to the periodic reports and `/ringkas`,
  for example "bulan ini 20% lebih boros untuk makan".
- Only show significant changes (for example ≥ 10% and ≥ Rp20rb).

## Acceptance criteria
- [ ] Unit tests for a previous period of zero (no division by zero).
- [ ] Comparisons use equivalent periods (week over week, month over month).

## Dependencies
RUPI-306.
